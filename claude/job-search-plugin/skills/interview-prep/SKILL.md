# Interview brief

Read `profile.md`. Ask only for what is missing: company, role, date, interviewer name, and which round (HR screen, hiring manager, home task, panel).

## Build, in this order
1. **60-second pitch** in the user's language: who I am, what I did that matters for this role, why this company. Spoken style, not CV style.
2. **The company in 5 lines**: what it sells, to whom, how it makes money, one recent news item with its date and link.
3. **The interviewer**: role and background from public sources only, with links. Skip if nothing public.
4. **8 likely questions** for this round. For each: a STAR answer built only from confirmed facts (Situation, Task, Action, Result), 4 short lines.
5. **The hard question** the user fears most (a gap, a missing skill) with an honest answer that turns to what they did instead.
6. **4 questions to ask them**, specific to this company.
7. **Salary**: ask their range first; the user's number comes from the profile, never from you.

## Rules
- Never invent a story or a result. If a STAR answer needs a fact the profile lacks, mark it `[to fill]`.
- One page. If the user wants a page or artifact, keep it phone-friendly.
